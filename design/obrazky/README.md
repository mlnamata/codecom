# Obrázky ke generování

`prompty.txt` je vstup pro skill **gemini-obrazky-basic** (skript `prompty.py`, model `gemini-2.5-flash-image`). Každý blok `===` je jeden obrázek a jeho název je název souboru. Všechny jsou pro smyšlenou obec Javoří Lhota.

| Blok | Kam patří |
| --- | --- |
| sablona-01 až sablona-20 | úvodní obrázek šablon 01–20 (Náves, Zvonice, Studánka, Lípa, Májka, Hnízdo, Hranice, Vinice, Hřeben, Rynek, Radnice, Kolonáda, Mlýn, Hráz, Lupa, Kompas, Magistrát, Zpravodaj, Mikroregion, Úřad) |
| prezentace-* | prezentační web CodeKom: starosta s tabletem, hlavice topení v sále, zámek s klávesnicí |

Prompty jsou krátké a anglicky, protože tak generátor funguje nejspolehlivěji a nejlevněji. Styl je u všech stejný: dokumentární fotka bez textu a bez rozpoznatelných tváří.

Šablony mají kreslené ilustrace (SVG), které se barví podle palety. Fotky jsou alternativa pro obce, které chtějí fotografický úvod. Na skutečném webu má vždy přednost vlastní fotka obce.
