# Obrázky ke generování

`prompty.txt` je vstup pro skill **gemini-obrazky-basic** (skript `prompty.py`). Jeden řádek je jeden obrázek, všechny pro smyšlenou obec Javoří Lhota.

| Řádek | Kam patří |
| --- | --- |
| 1–20 | úvodní obrázek šablon 01–20 (Náves, Zvonice, Studánka, Lípa, Májka, Hnízdo, Hranice, Vinice, Hřeben, Rynek, Radnice, Kolonáda, Mlýn, Hráz, Lupa, Kompas, Magistrát, Zpravodaj, Mikroregion, Úřad) |
| 21–23 | prezentační web CodeKom: starosta s tabletem, hlavice topení v sále, zámek s klávesnicí |

Prompty jsou anglicky, protože tak generátory obrázků fungují nejspolehlivěji. Každý prompt chce dokumentární styl bez textu a bez rozpoznatelných tváří.

Šablony mají kreslené ilustrace (SVG), které se barví podle palety. Fotky jsou alternativa pro obce, které chtějí fotografický úvod. Na skutečném webu má vždy přednost vlastní fotka obce.
